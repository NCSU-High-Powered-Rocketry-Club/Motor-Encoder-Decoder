This board is for HPRC's 2026 - 2027 rover payload.

It uses a Motoron M2T256 Dual I2C Motor Controller and powers two 12V DC motors using JST connectors. Encoder position is received through these connectors and counted with the LS7866C quadrature counter. This data is retrieved off the board using the same i2c bus that controls the motors.
